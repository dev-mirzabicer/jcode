# Execution producer integration ledger

This is an **in-progress WP-02 inventory**, not package acceptance. Current source
is authoritative. A passing shared-wrapper test does not prove an adapter retained
bytes it had already clipped or converted destructively.

## Unfinished producer/caller reconciliation

- Agent/SDK history caps and provider-supplied tool-result paths.
- Agentgrep, search/session search, browser and deeper native-helper conversions.
- Mutation receipts/diffs, self-development and other owned helper output.
- Legacy background output previews versus canonical retained bytes.
- PDF/image/derived-text and managed live-output read continuation.
- All registered remaining tools, logging/label-only limits, and acquisition bounds.

For each remaining site, classify whether it selects the requested operation,
limits acquisition with an honest outcome, shortens a UI/log label, or loses part
of a selected producer result. Only the last category is fixed by removing a
producer presentation cap. Do not mechanically delete every `take` or `truncate`.

## Verification limits

Native runtime evidence is macOS arm64 unless an individual test says otherwise.
No prompt-prose quality test, hosted-model benchmark, unrelated desktop mutation,
user-output deletion, or stronger-than-configured archive isolation is implied.
The complete A14–A20/A25/A27–A30/A33 matrix and final activation remain required.
