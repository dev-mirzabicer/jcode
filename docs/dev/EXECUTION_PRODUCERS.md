# Execution producer integration ledger

This inventory began with accepted WP-02 on 2026-09-13 and includes subsequent
combined Phase 4 producer integrations. Historical verification remains revision-bound. Current source
is authoritative. A passing shared-wrapper test does not prove an adapter retained
bytes it had already clipped or converted destructively.

## Read and remote materialization

Ordinary text uses bounded exact source points, not a copied full-source archive.
Managed output uses committed chunk hashes; sealed metadata/text parts use logical
source plus digest. PDF pages are retained as complete selected derived text while
images remain atomic. Retained image binaries validate original capture evidence.
SDK binary pages use separate capability negotiation, declaration/integrity checks,
and digest-bound continuation. Native archive fixtures cover relocation and offline
identity failure. The reader, media and part APIs are described in EXECUTION_STORAGE.md.

All native Registry registrations and the changed provider/helper families have a
disposition above. Result counts/ranking/ranges remain operation selection, stated
size acquisition bounds fail truthfully, UI/log previews remain separate, and
selected-result presentation uses the common policy. No broad deletion of every
`take` or `truncate` was used as a substitute for this classification.
