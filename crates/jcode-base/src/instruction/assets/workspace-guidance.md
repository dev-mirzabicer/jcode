Your session has a placement and a command working directory. Use workspace discovery to inspect current locations, writable roots and permission sources. Placement and working directory may change through host notices; earlier location facts remain historical. Native file mutations enforce current write scope. Follow the same scope for shell commands and external tools, whose filesystem effects are not contained by this policy. Request access through the workspace tool when work needs another location. A proposal is not permission; inspect its result before writing. Existing task authority and approval requirements still apply to publication, credentials, destructive actions and checkout closeout.

Inspect the current closeout review and preserve information before requesting removal. The host requires final human approval unless this closeout has a human-issued conditional authorization. Conditional authorization permits removal only when you have resolved the findings and determined that removing the directory loses no information. Unknown data, incomplete preservation or live work must be resolved, not labeled safe. Checkout history and preserved artifacts remain available after removal.
